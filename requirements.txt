===========================================================
 SQL DATA WAREHOUSE PROJECT - REQUIREMENTS & SETUP GUIDE
===========================================================

This project is 100% SQL-based. No Python/pip packages are
required. This file lists the tools and setup needed to run
the project locally.

-----------------------------------------------------------
 1. TOOLS REQUIRED (All Free)
-----------------------------------------------------------
[ ] SQL Server Express (2019 or later)
      -> Database engine used to host the warehouse
      -> Download: https://www.microsoft.com/en-us/sql-server/sql-server-downloads

[ ] SQL Server Management Studio (SSMS)
      -> GUI client used to run and manage SQL scripts
      -> Download: https://learn.microsoft.com/en-us/sql/ssms/download-sql-server-management-studio-ssms

[ ] Git
      -> Required for version control and cloning this repo
      -> Download: https://git-scm.com/downloads

[ ] Draw.io (optional)
      -> For viewing/editing architecture and data flow diagrams
      -> https://www.drawio.com/

[ ] Notion (optional)
      -> For project planning / documentation reference
      -> https://www.notion.com/templates/sql-data-warehouse-project

-----------------------------------------------------------
 2. PROJECT DATA
-----------------------------------------------------------
[ ] Sample CSV files (already included in this repo)
      -> Location: /Datasets/source_crm
      -> Location: /Datasets/source_erp

-----------------------------------------------------------
 3. SETUP STEPS
-----------------------------------------------------------
 Step 1: Install SQL Server Express + SSMS
 Step 2: Clone this repository using Git
 Step 3: Open SSMS and connect to your local SQL Server
 Step 4: Run scripts in this order:
             Scripts/bronze  -> creates & loads raw tables
             Scripts/silver  -> cleans & transforms data
             Scripts/gold    -> creates final business views
 Step 5: Run scripts inside /Test to validate data quality

-----------------------------------------------------------
 4. FOLDER REFERENCE
-----------------------------------------------------------
 Datasets/source_crm   -> Raw CRM CSV files
 Datasets/source_erp   -> Raw ERP CSV files
 Scripts/bronze        -> Raw data ingestion scripts
 Scripts/silver        -> Data cleaning & transformation scripts
 Scripts/gold          -> Business-ready views (star schema)
 Test                  -> Data quality / validation scripts
 README.md             -> Full project overview
 gitignore.txt         -> Ignored files and folders
